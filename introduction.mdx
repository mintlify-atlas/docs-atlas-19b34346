OmniRoute is a free, self-hosted AI gateway that collapses 350+ AI providers — OpenAI, Anthropic, Gemini, xAI, DeepSeek, Mistral, Qwen, and hundreds more — behind a single OpenAI-compatible endpoint at `http://localhost:20128/v1`. Instead of juggling a dozen SDKs, rotating API keys by hand, and debugging rate-limit failures mid-session, you point every coding tool and CLI agent at OmniRoute once, and it handles routing, fallback, compression, and quota tracking automatically.

## Zero-Config Start

A fresh install responds immediately — no API key, no signup, no configuration file. The `auto` model is pre-wired to keyless free providers so the gateway answers on the first request:

```bash
npm install -g omniroute
omniroute
# then send your first request:
curl http://localhost:20128/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
```

Dashboard opens at `http://localhost:20128`. API base URL is `http://localhost:20128/v1`.

## The `auto` Model and Its Variants

Set `model: auto` and OmniRoute builds a virtual combo from your connected providers, scored live on 15 factors including health, quota, cost, latency, and task fit. Specialised variants let you tune the optimisation axis without creating a manual combo:

| Model ID | What it optimises for |
|---|---|
| `auto` | Balanced default — sticks to your last good provider (LKGP) |
| `auto/coding` | Quality-first weights for code generation |
| `auto/fast` | Lowest latency first |
| `auto/cheap` | Cheapest per-token first |
| `auto/offline` | Most quota / rate-limit headroom first |
| `auto/smart` | Quality-first + 10% exploration to discover better models |

## 3-Layer Resilience Architecture

OmniRoute never fails silently on a provider error. Three independent self-healing layers handle failures at different granularities:

<Accordion title="Layer 1 — Provider Circuit Breaker (whole provider)">
Trips only on 408/5xx responses. Thresholds are `10×` for OAuth, `15×` for API keys, and `2×` for local providers. Resets into a HALF-OPEN probe after 60s / 30s / 15s respectively. While OPEN, the combo reroutes to the next healthy provider automatically.
</Accordion>

<Accordion title="Layer 2 — Connection Cooldown (one key/account)">
Base cooldown of 5s (OAuth) or 3s (API key) with exponential `×2` backoff and an anti-thundering-herd guard. 429 responses honour `Retry-After`. A single cooling key is skipped while sibling keys keep serving traffic — no full provider blackout from a single exhausted account.
</Accordion>

<Accordion title="Layer 3 — Model Lockout (one model)">
Per-model 429s, local 404s, or mode-denied responses lock just that model — never the full connection. Terminal states such as banned, expired, or credits-exhausted accounts are flagged for operator action rather than treated as transient cooldowns.
</Accordion>

## Compatible Coding Tools

OmniRoute exposes an OpenAI-compatible endpoint, so every tool that accepts a custom base URL works out of the box:

**Claude Code · OpenAI Codex · Cursor · Cline · GitHub Copilot · OpenCode · Kilo Code · Aider · Goose · Continue · Windsurf · Factory Droid · Zoo Code · Grok Build · Warp AI · Open Interpreter** — and any other OpenAI-compatible tool.

One-command launch for supported CLIs, no config files written:

```bash
omniroute run claude   --model auto
omniroute run codex    --model auto
omniroute run opencode --model auto
```

Or let OmniRoute write each tool's own config file:

```bash
omniroute configure codex   # writes ~/.codex/*.config.toml
omniroute configure claude  # writes ~/.claude/profiles/<name>/settings.json
```

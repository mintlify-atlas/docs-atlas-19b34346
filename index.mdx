## How OmniRoute works

OmniRoute runs as a local server on port `20128`. Point any OpenAI-compatible tool at `http://localhost:20128/v1`, set the model to `auto`, and OmniRoute takes care of everything else — routing, fallback, compression, and cost tracking.

<Steps>
  <Step title="Install OmniRoute">
    ```bash
    npm install -g omniroute
    omniroute
    ```
    The gateway starts at `http://localhost:20128`. The dashboard opens automatically.
  </Step>
  <Step title="Connect a free provider">
    Open the dashboard → **Providers** → **Add Provider** → select **Kiro AI**, **OpenCode Free**, or **Pollinations** — no credit card needed.
  </Step>
  <Step title="Point your tool at OmniRoute">
    ```
    Base URL:  http://localhost:20128/v1
    API Key:   [copy from Dashboard → Endpoints]
    Model:     auto
    ```
    Works with Claude Code, Codex, Cursor, Cline, Copilot, and any OpenAI-compatible client.
  </Step>
  <Step title="Verify it works">
    ```bash
    curl http://localhost:20128/v1/chat/completions \
      -H "Authorization: Bearer YOUR_KEY" \
      -H "Content-Type: application/json" \
      -d '{"model":"auto","messages":[{"role":"user","content":"Hello!"}]}'
    ```
    OmniRoute routes the request to the best available free provider automatically.
  </Step>
</Steps>
